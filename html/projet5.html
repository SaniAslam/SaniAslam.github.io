API The Movie Database (TMDB)

Projet 5

Application web en PHP qui exploite l'API publique de TheMovieDB pour afficher des films, leurs détails, les acteurs associés et permettre une recherche par titre ou par genre.

PHP API REST HTML/CSS JSON TMDB API

Description

Ce projet consomme l'API TMDB pour construire un mini site de films en PHP. L'objectif était de manipuler une API externe, structurer les requêtes dans des fonctions réutilisables, et afficher les résultats de façon claire.

Fonctionnalités principales

  • Films les mieux notés : récupération et affichage des films les mieux notés via une fonction dédiée (topRated).
  • Filtre par genre : un menu liste tous les genres TMDB (avec leur identifiant) et affiche les films correspondants via filmParGenre.
  • Fiche film : clic sur un film → page de détail (movieDetails.php) qui récupère l'identifiant du film dans l'URL et affiche ses informations, avec le casting sous forme de cartes défilantes horizontalement.
  • Fiche acteur : page dédiée à chaque acteur (actorDetails.php) affichant ses informations et une sélection de ses films principaux, chacun cliquable vers sa propre fiche.
  • Recherche : barre de recherche redirigeant vers searchMovies.php ou searchActors.php selon le type de recherche.
  • Bandes-annonces : affichage des trailers YouTube (VO et VF quand disponibles) via iframe sur la fiche film.
  • Thème sombre : mise en forme personnalisée via un fichier global.css dédié.

Ce que j'ai appris

Manipuler une API REST externe en PHP avec file_get_contents, structurer le code en fonctions réutilisables, passer des paramètres via l'URL ($_GET), et gérer l'affichage conditionnel de données (acteurs sans photo, trailer manquant, etc.).
